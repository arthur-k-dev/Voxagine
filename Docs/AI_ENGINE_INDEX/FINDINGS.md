# Voxagine engine review findings

This is the human-readable view of the canonical records in `findings.jsonl`. The machine file is authoritative for filtering and automation. IDs are stable across revisions; paths and symbols are more durable than the reviewed line hints.

Ratings use `priority / severity / status`. `P0` is the first remediation tier; `confirmed` means the defect is deterministic by source inspection; `concurrency-risk` means an unsafe interleaving exists and should additionally be reproduced under stress/sanitizers; `coverage-gap` and `limitation` describe verification or architectural constraints.

## Remediation order

The safest order is architectural rather than purely file-by-file:

1. Define shutdown/cancellation semantics and make job queues joinable before deleting worlds, systems, queues, logging, or editor targets (`VX-LIFE-001`, `VX-JOB-001` through `VX-JOB-004`).
2. Add strict JSON/VOX/chunk validation before allocations, indexed access, RTTR construction, or state mutation (`VX-SER-*`, `VX-VOX-*`, `VX-CHUNK-002`).
3. Snapshot or synchronize voxel/pathfinding state shared with workers; remove raw/ref captures into mutable containers (`VX-PHY-*`, `VX-CHUNK-001`, `VX-PATH-*`).
4. Fix deterministic supported-path crashes: controller indexing, format strings, editor command clearing, world stack guards, camera/null backend assumptions.
5. Repair and activate allocator/input/audio/time tests, then add full engine/editor CI plus sanitizer/fuzz jobs.

## Positive findings from the pulled voxel pass

These are not issue records, but they are important constraints for future work:

- CPU `Voxel` is four bytes and guarded by size assertions.
- Static ownership is separated into a compact `uint16_t` sidecar with explicit sentinel values.
- Chunk RLE has a round-trip audit path and deliberately excludes transient particle claims.
- Brick occupancy and far-field volume reduce sparse/distant processing.
- Several world/grid/renderer coordinate, upper-bound, owner, and NaN checks were added.
- `RenderContext::ModifyVoxel` now rejects upper-bound violations.
- Fade-time handling guards nonpositive durations.
- `Application` now guards its main-camera upload block.
- Null audio is a maintained backend rather than an absent-code conditional.

The review therefore recommends building on the current representation while fixing lifecycle, parser, and concurrency boundaries around it.
